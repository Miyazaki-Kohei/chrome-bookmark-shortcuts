# chrome-bookmark-shortcuts

ブックマークの追加と削除をショートカットで行う Chrome 拡張機能。追加と削除は別々の拡張機能になっている。

| ディレクトリ | 拡張機能 | ショートカット | 動作 |
|---|---|---|---|
| `bookmark-add/` | ブックマーク追加 | ⌥⇧B | フォルダを選んで、表示中のページをブックマークに追加する |
| `bookmark-remove/` | ブックマーク削除 | ⌥⇧X | 表示中のページのブックマークを削除する |

どちらもツールバーのアイコンからも使える。ブックマーク済みかどうかは、アドレスバーの星アイコンで確認できる。

## ブックマーク追加

⌥⇧B でポップアップが開く。

- フォルダ名を入力すると絞り込める（親フォルダの名前でも一致する）
- ↑↓ で選び、Enter で登録する。Esc で閉じる
- 並び順は、最近使ったフォルダ → 「その他のブックマーク」 → 残りをツリー順
- 登録済みのページでは「登録済み: フォルダ名」と表示し、選んだフォルダへ移動する（重複は作らない）

権限は `bookmarks`、`activeTab`、`storage`（最近使ったフォルダの記録）。

## ブックマーク削除

⌥⇧X で、表示中のページのブックマークを削除する。同じ URL が複数のフォルダにあれば、すべて削除する。

結果はツールバーのアイコンに一瞬表示される（`−` 削除した / `0` 登録されていなかった / `!` 失敗）。

権限は `bookmarks`、`activeTab`。

## インストール

1. `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」で `bookmark-add` を選ぶ。同じ手順で `bookmark-remove` も読み込む

ショートカットは `chrome://extensions/shortcuts` で変更できる。ほかの拡張機能が同じキーを使っていると割り当てられないので、そのときもここで設定する。

コードを変更したら、`chrome://extensions` で該当する拡張機能の再読み込みボタンを押す。
