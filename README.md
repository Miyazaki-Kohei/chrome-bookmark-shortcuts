# chrome-bookmark-toggle

ショートカット1つで、表示中のページのブックマークを追加・削除する Chrome 拡張機能。

## 動作

⌥⇧B（またはツールバーのアイコン）を押すたびに切り替わる。

- 未登録のページ → 「その他のブックマーク」に追加する
- 登録済みのページ → 削除する。同じ URL が複数のフォルダにあれば、すべて削除する

結果はツールバーのアイコンに一瞬表示される（`+` 追加 / `−` 削除 / `!` 失敗）。ブックマーク済みかどうかは、アドレスバーの星アイコンで確認できる。

権限は `bookmarks` と `activeTab` だけで、閲覧履歴は読まない。

## 構成

| ファイル | 内容 |
|---|---|
| `manifest.json` | 権限とショートカット（`Alt+Shift+B`）の定義 |
| `background.js` | 追加・削除の処理 |
| `icons/` | アイコン（16 / 32 / 48 / 128px） |

## インストール

1. `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」で、このディレクトリを選ぶ

ショートカットは `chrome://extensions/shortcuts` で変更できる。ほかの拡張機能が同じキーを使っていると割り当てられないので、そのときもここで設定する。

コードを変更したら、`chrome://extensions` でこの拡張機能の再読み込みボタンを押す。
